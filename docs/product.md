# ALTER · 另一个我 — 产品说明

> 版本：v1.1（留存迭代）｜面向：中国 12–18 岁青少年｜形态：Web / PWA

---

## 1. 一句话定位

**ALTER 是一款「英语分身」剧情口语 App：你每天用英语活 3 分钟另一种人生，而不是背 20 个单词。**

不是单词本，不是打卡器，也不是选择题闯关。玩家进入一个个真实的中国校园/生活场景，扮演自己的英语分身，**说出**该说的话，剧情因此往前走。

---

## 2. 为什么是它：差异化核心玩法

### 2.1 竞品的问题（针对青少年）

| 产品 | 核心机制 | 青少年的真实感受 |
|---|---|---|
| 百词斩 | 图背单词 + 打卡 | 认识中文意思 ≠ 会用；图看多了只记住图 |
| 扇贝 | 单词/听力/打卡体系 | 任务感强，像作业；缺"我想打开"的理由 |
| 不背单词 | 例句沉浸背词 | 输入型，仍然不说话 |
| 多邻国 | 关卡化题目 + 连胜 | 好玩但"游戏是游戏、英语是英语"，短句碎片、无叙事，青少年很快看穿它是练习题 |

共同缺口：**都在训练"记住"，没有在训练"我敢说、我会说"。** 而青少年的真实痛点是——课堂上被点名说不出话、想回一条英文评论、想看懂偶像的直播，却张不开嘴。

### 2.2 ALTER 的三个差异点

**① 输出驱动：不选意思，而是"组出你要说的那句话"**
每一幕给出中文意图（"她问你旁边有人吗，让她坐"）+ 一堆**词块**（不是单词，是 `go ahead` / `if you don't mind` / `came out wrong` 这样的语块）。玩家用词块拼出句子，提交后立刻得到：

- **地道度判定**（地道 / 能懂 / 词对但顺序不对 / 差一点 / 再想想）
- **母语者版本 + 一句"为什么这么说"**
- 不及格就重来 —— **掌握才放行**，不是做错也能打卡。

这一步把"背过"变成"用过"，而且一次只花 20 秒。

**② 剧情连载 + 人设：给的是"我是谁"，不是"我学了几个词"**
5 个场景是连续剧：开学第一天 → 食堂 → 群聊误会 → 社团面试 → 考前一晚；第 2 季走到校外，第 3 季走向毕业和面试。每集结尾有**二选一的分支**，选择会被记住并写进结算；下一集开头承接上一集的结果。青少年追的是"后来呢"，不是"连续打卡 7 天"。

**③ 名场面卡：可分享的社交货币**
每集结算会生成一张竖版「名场面卡」（你的角色、对方台词、你最后说出口的那句地道英文，加上集数、本集地道句数和一个**指向线上版的二维码**）。可以下载发朋友圈/群，扫一下就能进同一集。这是 ALTER 的增长引擎，也是青少年愿意"被看见"的动机。

### 2.3 一句话对比

> 百词斩让你**认识**一个词，多邻国让你**选对**一个句子，ALTER 让你**说出一句属于你的台词**，并且明天还有下一集。

## 3. 核心使用闭环

```
打开 → 首页「今天的 3 分钟」（只给今天这一集）
  ↓
看 NPC 台词（可听发音）+ 中文情境 + 你的人设标签
  ↓
点词块组句 → 提交
  ↓ 不及格：给差异提示（缺哪个词/顺序错了）→ 再试
  ↓ 通过：显示母语者版本 + 地道点解释 → 继续
  ↓
本集最后一幕 → 二选一分支 → 结算（地道句数 / XP / 连击天数）
  ↓
生成「名场面卡」（带二维码）→ 下载分享 / 收藏金句到句子本
  ↓
明天回来：下一集自动解锁；说错或只说「能懂」的句子进入复习队列
```

- **单次时长**：一集 3 分钟，正好是课间/睡前的碎片时间。
- **每日节奏**：默认一天解锁一集，首页只突出「今天的 3 分钟」，不再把 15 集摊开让人挑；想连看的人可以提前解锁，卡片会明确标记「提前解锁」，第二天照常更新。
- **复习闭环**：答错 → 当天进入复习队列；只说「能懂」→ 3 天后再来；复习中答对才移出，答错推到明天。句子本从「收藏夹」升级成「复习队列」。
- **习惯钩子**：连载悬念（明天还有下一集）+ 复习到期提醒 + 连击天数 + 句子本积累。
- **失败成本**：极低，重来即可，从来不会"今天白来了"。

## 4. MVP 范围

### 4.1 本轮做（已实现）

| 模块 | 内容 |
|---|---|
| 场景内容 | **3 季 15 集，45 幕（Act），135 个作答回合**，全部为真实可用的地道口语；场景覆盖校园、兼职面试、独自旅行、家庭谈判、和外国网友语音、毕业告别 |
| 核心玩法 | 词块组句 + 五档地道度判定 + 母语者版本 + 知识点解释 + 掌握才放行 |
| 剧情 | 每集 2 选 1 分支、结算文案、下一集解锁；第 2 集起用 `callbacks` 把上一集的选择写进本集开场，选了就有下文 |
| 每日节奏 | 首页只给「今天的 3 分钟」；下一集默认次日解锁；想连看可提前进入，卡片明确标注「提前解锁」，不硬卡 |
| 复习队列 | 答错当天到期，只说「能懂」3 天后到期；复习答对移出，答错推到明天；句子本顶部显示到期句数 |
| 人设 | 3 种人设（暖场怪 / 嘴替 / 气氛组），影响结算文案与卡片配色 |
| 成长 | XP、连击天数（本地日期）、地道句数、总进度 |
| 资产 | 「名场面卡」Canvas 生成并下载 PNG，卡上带集数、地道句数和**可扫描的线上二维码**；句子本收藏/朗读/删除 |
| 发音 | Web Speech API 朗读 NPC 台词与参考句（浏览器原生，零成本） |
| 工程 | 纯静态、零依赖、双击 `index.html` 即可运行；首屏只加载第 1 季，第 2/3 季空闲时按需注入；首屏骨架 + 容错 Service Worker（http 下可安装/离线，弱网不白屏） |
| 质量 | 51 条自动化测试（评分器/进度/解锁/持久化 + 每日节奏 + 复习调度 + 二维码 + 内容完整性校验 + 分支承接 + 英文语料 + 135 回合端到端），Node 与浏览器双入口 |

### 4.2 本轮明确不做（并说明原因）

| 不做 | 原因 |
|---|---|
| 账号 / 云同步 | MVP 用 localStorage 足够验证闭环；接账号会拖慢验证，且需要外部服务 |
| 真实 LLM 自由对话 | 需要密钥与费用；本轮用「多解 + 词块」保证可判分、可离线、零成本 |
| 语音识别打分 | 浏览器兼容性差、准确率不足以做分数；先做"听 + 读出来"，不做评分误导用户 |
| 好友 / 排行榜 / 公会 | 需要后端与内容审核；青少年社交功能涉及合规，放到有服务端时再做 |
| 支付 / 订阅 | 不影响验证核心玩法 |
| 全量词库 / 语法课 | ALTER 不是课程产品，避免回到"学习资料库"的老路 |

### 4.3 内容分级

- 第 1 季 A2–B1，第 2 季 B1，第 3 季 B1–B2；句子逐季变长，提示逐季变少。
- 语料来自真实青少年口语：省略句（`Brutal how?`）、缓冲词（`I mean`）、俚语标注（`mid` / `goes hard` / `sus`），并在解释里说明使用场合，避免学生乱用。
- 每集至少 1–2 条 `ok` 级第二答案，保证"意思对了但说法不同"也能通过，而不是只认一个标准句。
- 地道点解释统一控制在两句以内，只讲"为什么这么说 / 什么场合用"，不讲语法课。

## 5. 关键决策记录（Decision Log）

1. **先做"说"而不是"背"**：竞品在"记"上已极致，差异化只能在输出侧。多解判分足以支撑"说"的体验，无需 LLM。
2. **掌握才放行**（pass-gate）：不做"错了也能过"，否则回到刷关。代价是可能卡住，用"两次失败给首词提示"兜底。
3. **分支只做 2 选 1，且不影响后续正确率**：剧情感优先，不做复杂分支树（内容成本指数增长）。
4. **零依赖 + 无构建**：保证"双击就能跑"，也便于后续静态托管（GitHub Pages / Vercel / 对象存储）。
5. **localStorage 作为唯一存储**：单机可玩、无隐私上传；后续做同步时再抽象 storage 层（引擎已与存储解耦）。
6. **Canvas 生成分享卡而非截图**：保证品牌一致、可离线、可批量导出。
7. **内容按季拆文件，且首屏只加载第 1 季**：15 集放进单文件会让首屏脚本变大、编辑冲突变多；第 2/3 季在空闲时注入，首屏先渲染今天的 3 分钟，弱网也有骨架屏而不是白屏。
8. **分支承接用数据而不是 if**：每集带 `callbacks`（key = 上一集分支 id），引擎 `sceneCallback` 只负责查表；内容校验器强制覆盖上一集每个分支，避免"选了没下文"。
9. **每日节奏不做硬锁**：默认次日解锁，但提前进入始终可用，只做视觉标记。留存靠"明天有新的"和复习到期，而不是惩罚连看的人。
10. **复习移出只认复习环节的答对**：剧情里改口说对，句子仍留在队列里等复习确认；避免"错一次→当场蒙对→永远消失"。答错复习推到明天，不羞辱、不清零。
11. **二维码用内置固定版本编码器**：只需 Version 4 / L / Mask 0，约 200 行，零依赖、可离线、可在 Node 里做结构测试；不引入网络生成的短链服务。

## 6. 成功指标（上线后）

- 激活：首集完成率 ≥ 60%
- 留存：次日回访 ≥ 35%，7 日 ≥ 15%（以"完成 1 幕"计）
- 核心行为：平均每幕重试次数 1.2–1.8（太低=太简单，太高=挫败）
- 传播：名场面卡下载/分享率 ≥ 12%
- 学习效果（自评）：句子本 7 日新增 ≥ 5 条

## 7. 迭代路线

**v0.2（内容与手感）**
- 场景扩到 12 集（加"和爸妈吵架""打工第一天""游戏开黑""追星评论区"）
- 每题支持"听写模式"与"跟读提示"
- 难度自适应：同一幕按历史正确率调整提示强度

**v0.3（语音与社交）**
- Web Speech 识别 + 发音对比（仅提示，不打分）
- 名场面卡模板 5 套、可换字体/配色
- 本地"好友挑战码"：分享一个场景链接，对方完成后回传成绩（无需账号）

**v1.1（留存迭代，已完成）**
- 每日节奏：首页只给「今天的 3 分钟」，次日解锁，提前看有标记
- 复习闭环：说错 / 只说「能懂」的句子按遗忘节奏回到复习队列，答对才移出
- 分享卡带二维码：卡上集数、地道句数、台词，扫码直达线上
- 首屏按需加载三季 + 骨架屏 + 容错离线缓存

**v1.0（账号与商业化）**
- 轻后端（Supabase / 云开发）：账号、云同步、周报
- 校园限定剧情季（与真实校园节点绑定：开学、期末、毕业）
- 订阅：剧情季 + 无限重听 + AI 陪练（此时才引入 LLM）

## 8. 合规与安全（青少年产品必须）

- 无陌生人社交、无 UGC 公开展示、无地理位置。
- 不采集个人信息；进度仅存本地，用户可一键清除。
- 内容不含恋爱引导、外貌评价、攀比消费；冲突场景以"修复关系"为落点。
- 明确非应试承诺：不宣称提分，主打"敢开口"。
