# ALTER · 另一个我（中文详细文档）

> **英语分身剧情口语 App**：每天用英语活 3 分钟另一种人生，而不是背 20 个单词。
> 面向中国 12–18 岁青少年 · 纯静态 Web / PWA · 零依赖 · 双击即开。
>
> English overview: [../README.md](../README.md) · 产品说明：[product.md](product.md)

---

## 快速开始

### 方式一：直接双击（最快）

打开 [index.html](../index.html) 即可。无需安装、无需联网、无需构建。

> 说明：`file://` 下所有核心功能都可用（含进度保存、Canvas 名场面卡）。Service Worker 只能在 http/https 下注册，所以"安装到桌面 / 离线缓存"需要方式二。

### 方式二：本地服务器（推荐，可测试 PWA）

```bash
cd alter
py -m http.server 8765        # Windows（或 python3 -m http.server 8765）
# 打开 http://127.0.0.1:8765/
```

Chrome / Edge 地址栏会出现"安装"图标，可装成桌面或手机 App；断网后仍可打开。

### 方式三：任意静态托管

整个 `alter/` 目录上传到 GitHub Pages / Vercel / 对象存储即可，无需服务端。

## 玩法（核心闭环）

1. **选人设**：暖场怪 / 嘴替 / 气氛组。人设决定每一集结尾的旁白和名场面卡配色。
2. **看今天这一集**：首页只给「今天的 3 分钟」；默认一天解锁一集，想连看可以提前进入（会标「提前解锁」，第二天照常更新）。
3. **进入一幕**：看 NPC 台词（可点「听一遍」朗读）+ 中文情境 + 你的任务（中文意图）。
4. **用词块拼句子**：从词块池点选，拼出你要说的话。词块里带干扰项。
5. **拿到判定**：
   - 地道 / 能懂 → 通过，显示母语者版本 + 一句"为什么这么说"，+10 / +7 XP；
   - 顺序不对 / 还差一点 / 再想想 → 不通过，提示缺哪个词、错在语序；失败 2 次给首词提示，3 次给参考答案。
6. **开口说（可选）**：拼好之后点「🎙 开口说」，对着麦克风把这句话念出来。浏览器识别出的文字会跟参考答案做宽容比对（缩写、连读、语气词、小的语序偏差都容忍），给出「说对了 / 差一点 / 没听清」并列出没对上的词。语音只判断"有没有真的说出口"，分数仍按词块判定。首次使用有一次性引导；拒绝麦克风或不支持时自动回到点词块交卷，不弹错误框。
7. **剧情推进**：9 幕之后二选一分支，选择被记住，写进结算。
8. **结算**：地道句数 / 本集 XP / 连击天数 + 分支结局 + 人设旁白 + Canvas 名场面卡（带二维码，可下载）+ 下一集悬念。
9. **复习闭环**：答错当天进复习队列，只说「能懂」3 天后再来；在复习里答对才移出，答错推到明天。句子本顶部会显示今天到期的句数。

隐私口径：不录音、不上传、不保存音频；识别由浏览器完成，只在本机拿识别文字做比对。语音可随时关掉。

设计取舍：**掌握才放行**（做错也能过就变回刷关），但提供逐级提示与"照着拼"兜底。

## 技术栈

| 层 | 选择 | 原因 |
|---|---|---|
| 前端 | 原生 HTML / CSS / JavaScript（ES5 语法为主，无框架、无打包） | 双击即开；后续可无痛迁移到任意框架 |
| 逻辑 | `src/engine.js`：UMD 纯函数（评分 / 进度 / 解锁 / 每日节奏 / 复习调度 / 持久化 / 校验） | 与 DOM 完全解耦，可在 Node 与浏览器里跑同一套测试 |
| 内容 | `src/content.js`（第 1 季）+ `src/seasons/season2.js`、`season3.js`，由 `src/catalog.js` 合并；`index.html` 首屏只加载第 1 季，其余空闲时按需注入 | 首屏更快；弱网先看到今天的 3 分钟；仍是零依赖、零构建 |
| 存储 | `localStorage`（单键 `alter.state.v1`，带版本号与容错迁移） | 无账号、无后端、无隐私上传 |
| 发音 | Web Speech API（`speechSynthesis`） | 浏览器原生，零成本零密钥；不可用时按钮会提示 |
| 开口说 | Web Speech API（`SpeechRecognition`）+ `src/speech.js` 宽容比对 | 只看识别文字，不录音不上传；不支持/拒绝时自动降级为词块交卷 |
| 分享卡 | Canvas 2D 现画 1080×1350 PNG，右下角二维码由 `src/qr.js` 生成 | 离线可用、品牌一致；扫码直达线上 |
| 离线 | `manifest.webmanifest` + `sw.js`（cache-first、逐个缓存、导航失败回首页） | 可安装、可离线、弱网不白屏；`file://` 下自动跳过注册 |
| 测试 | 自研 40 行断言框架（`tests/harness.js`） | 零依赖、Node 与浏览器双入口 |

> 没有使用任何第三方库、CDN、字体或图片资源；没有写入任何密钥；没有安装任何系统级服务。

## 测试

### 运行（任选其一）

```bash
node tests/run.js          # Node >= 12，零依赖
npm test                   # 同上
```

或直接用浏览器打开 `tests/test.html`（无需安装任何东西）。

当前结果：**78 / 78 通过**。

### 覆盖范围

**评分器**
- 大小写 / 标点 / 弯引号 / 缩写归一化
- 完全命中母语者说法 → `native` 100 分
- 命中可接受说法 → `ok` 82 分
- 词全对但语序错 → `order` 不通过
- 多词/缺词 → `close` 并列出缺失词
- 完全不相干、空作答 → `off`
- 多参考答案时取最高分（不会因为先匹配到低分句而误判）
- 缺 `solutions` 的坏数据直接抛错，不静默通过

**进度与状态**
- 首次通过加 XP；重复通过不加（防刷分）；失败记录尝试次数
- 场景统计、解锁链（上一集全通才解锁下一集）
- `nextUp` 跳过已通过回合
- 场景状态机 `locked → active → choice → done`
- 人设结算文案兜底、总览统计

**容错与存储**
- 空数据 / 字符串 / 版本不符 → 退化为全新状态，不崩
- 合法数据完整保留
- 句子本收藏 / 去重 / 取消
- 连击：同日不变、隔日 +1、断档重置

**每日节奏**
- 新用户的第一集就是「今天」
- 今天通关后，下一集标记为「提前解锁」但仍可进入（不硬卡）
- 第二天回来，下一集变成「今天的 3 分钟」
- 老存档缺少 `completedOn` 时按今天可玩处理，不把人锁死
- 全部通关后不再给出新的一集

**复习队列**
- 答错 → 当天到期；只说「能懂」→ 3 天后到期
- 剧情里改口说对，仍留在队列等复习确认；一次就地道则不进队列
- 复习答对移出；复习答错推到明天并累计失误
- 迁移保留合法队列条目，坏数据被丢弃

**二维码**
- 线上地址生成 33×33，三个定位图形完整
- 时序图案交错、固定暗模块存在、暗模块比例合理
- 同样输入输出稳定
- 超出容量直接抛错，不生成坏图

**语音判定（`src/speech.js`）**
- 逐字念对 → 说对了；大小写 / 标点 / 空格不影响
- 缩写互通（`I'm gonna` ↔ `I am going to`）、连读弱写（`lemme` → `let me`）能对上
- 小的语序偏差仍算说对了；多词漏说 → 差一点并列出漏掉的词
- 完全跑偏 / 空识别结果 → 没听清；语气词（um/uh）不算多说
- 多个参考答案时取最匹配的一条；缺 `solutions` 抛错
- 识别控制器用**假识别器**测试：正常结果、麦克风拒绝、主动取消、不支持，全程不碰真实麦克风

**本机埋点与周报（`src/analytics.js`）**
- 事件写入事件名、本地日期、时间戳；超过 500 条自动裁掉最旧的
- 迁移会丢弃坏事件（空名、坏日期、缺时间戳），坏数据不崩
- 隐私字段（`text` / `line` / `transcript` 等）即使误传也不会落库
- 漏斗计数与去重（打开、选人设、开始一集、完成整集、生成/保存分享卡、次日回访）
- 每日活跃只统计最近 N 天；平均每集完成幕数、语音使用比例、分享率（含除零保护）
- 周报：7 天窗口、学习天数 / 完成集数 / 地道句 / 开口次数 / 复习清空 / 与上周趋势
- 建议由真实数据生成：学习天数少 → 固定时段；开口少 → 先开口；复习积压 → 先清复习；无数据 → 温和起步
- 导出 JSON 可解析、带上限与条数、不含隐私字段

**内容完整性（重点）**
- 场景/幕/回合 id 唯一
- 每个回合必须有台词、中文翻译、情境、意图、地道点
- **每个参考答案的单词都必须能在词块池里拼出来**（multiset 校验，防止"答案拼不出"的线上事故）
- 每集必须有二选一分支且两个结局不同
- **分支承接**：第 2 集起每集必须有 `callbacks`，且覆盖上一集两个分支各自的承接文案；不同选择确实产生不同开场
- 三季各 5 集、难度逐季上升；英文台词与参考答案不得含中文；地道点不超过两句
- 每种人设都必须有结算文案
- 禁止占位文本（TODO / 占位 / lorem）
- 校验器本身有"能否抓出坏数据"的反向测试

**端到端**
- 用参考答案模拟走完 135 个回合：15 集全部可通关、XP = 1350、地道句 = 135、`nextUp` 返回 null
- 第一集通关后第二集解锁

### 手动验收（浏览器）

`tests/seed.html` 是给 QA 用的进度夹具：

- `tests/seed.html` → 第 1 集全通过并已选分支，用来直接看**结算页 / 名场面卡**
- `tests/seed.html?mode=last` → 只差最后一幕，用来验收**最后一幕 → 分支页 → 结算**
- `tests/seed.html?unlock=first-shift` → 自动做完前面所有集并选好分支，直接验收**第 2 季第 1 集**（任意场景 id 均可）
- `tests/seed.html?day=yesterday` → 完成日期记为昨天，用来验收**第二天回来**（首页应变成下一集的「今天的 3 分钟」）
- `tests/seed.html?mode=review` → 第 1 集完成 + 一句今天到期的复习句，用来验收**复习队列 → 答对移出**

v1.1 的三个实机场景：

1. **新用户第一天**：清掉 `alter.state.v1` 后打开 App → 首页只显示「今天的 3 分钟」和本季 5 集；15 集收在「全部剧集」折叠里；完成一集后首页出现「已完成 ✓」和「提前解锁」标记，下一集仍可进入。
2. **第二天回来**：`seed.html?day=yesterday` → 首页回到「今天的 3 分钟」，正是下一集，没有「已完成」。
3. **答错后复习**：`seed.html?mode=review` → 首页/句子本显示「1 句到期」；进入复习答对后队列清零，刷新仍在。

v1.2 的两条实机路径（手机视口 390×844，Edge headless）：

1. **允许麦克风**：拼好词块 → 点「开口说」→ 首次引导（为什么开口 / 会弹授权 / 随时可关）→ 念出整句 → 显示「说对了」和识别文本 → 交卷得到原有五档分数。
2. **拒绝麦克风**：授权被拒后不弹窗，自动收起语音入口并提示「用词块交卷一样能过」；点「交卷」正常判分。运行时移除识别能力也会显示「不支持语音识别」，同样可交卷。

语音识别本身用注入的假实现验收（`window.SpeechRecognition`），不依赖真实麦克风；两条路径控制台均无报错。

v1.3 的实机验收（手机视口 390×844，Edge headless）：

1. **新用户完整一集**：清空本地数据 → 选人设 → 第一幕开口说 → 其余八幕词块 → 选分支 → 保存分享卡。逐条核对本机事件：打开 1、选人设 1、开始一集 1、完成幕 9、完成整集 1、开口 1、生成卡 1、保存卡 1。
2. **隐藏数据页**：连点左上角 ALTER 标志 5 次进入；漏斗各步数字与事件日志逐项一致；14 根日活跃柱、平均 9 幕/集、语音 11%、分享率 100%。
3. **导出**：点「导出埋点 JSON」下载文件，条数与事件总数一致，文件内没有 `transcript`。
4. **家长周报**：`#report` 打开；学习天数 1、完成集数 1、地道句 9、开口 1、复习清空 0、本周 9 幕，与真实游玩一致；建议包含具体数字；页面不含任何台词原文；用 Chrome/Edge 打印为 PDF 可单页保存。
5. **第二天回访**：把事件日期整体挪到昨天后重新打开 → 自动写入 `day2_return`，数据页「次日回访」变为 1，打开天数变为 2。

全程控制台零报错；语音识别仍用注入的假实现。

## 加一集内容（不需要改代码）

新集数写进对应的季文件（第 2 季 `src/seasons/season2.js`，第 3 季 `src/seasons/season3.js`）。若不是第一集，必须带 `callbacks`：用上一集两个分支的 id 作 key，各写一句"本集如何承接"。然后跑测试：

```js
{
  id: 'new-scene',
  season: 2,                // 1 / 2 / 3
  title: 'English Title', cn: '中文标题', emoji: '🎧',
  level: 'B1', minutes: 4, hook: '一句话悬念',
  callbacks: {              // 第 2 集起必填；key = 上一集分支 id
    a: '选了 A 的人，这一集开场看到的是……',
    b: '选了 B 的人，这一集开场看到的是……'
  },
  cast: [{ name: 'NPC', avatar: '🙂', role: '角色' }],
  acts: [{
    id: 's16-a1', title: 'Act 1 · 场景名',
    beats: [{
      id: 's16-a1-b1',
      speaker: 'NPC', avatar: '🙂',
      line: 'NPC 的英文台词', lineCn: '中文翻译',
      situation: '画面/情境描述',
      intent: '你要表达的中文意图',
      chips: ['词块', '带干扰项'],
      solutions: [
        { text: 'Native version.', level: 'native', note: '为什么这么说' },
        { text: 'Acceptable version.', level: 'ok', note: '能懂但不够地道' }
      ],
      tip: '这条语言点，最多两句'
    }]
  }],
  choice: {
    prompt: '二选一的抉择时刻',
    options: [
      { id: 'a', label: '选项 A', reply: '你做出的动作', outcome: '结局描写' },
      { id: 'b', label: '选项 B', reply: '你做出的动作', outcome: '另一个结局' }
    ]
  },
  personaClose: { warm: '暖场怪旁白', snark: '嘴替旁白', chaos: '气氛组旁白' }
}
```

只要 `node tests/run.js` 里的内容校验通过，这集就能跑（词块不足、id 冲突、缺字段、callbacks 漏分支都会被告知）。新增一整季时，再建一个季文件，并在 `src/catalog.js` 的 `sources` 与 `index.html` 的按需加载逻辑、`sw.js` 的缓存清单里登记。

## 已知限制

- **TTS 音色取决于系统**：Windows 上英文语音可能偏机械；没有网络语音，因为不想引入密钥。
- **`localStorage` 是单机的**：换浏览器/清缓存会丢进度；已预留 `engine.js` 与存储解耦，接后端时只需替换 `loadState/persist`。
- **`file://` 下不注册 Service Worker**：这是浏览器安全限制，不影响任何玩法；需要离线安装请用 http 方式打开。
- **名场面卡下载**：部分移动端浏览器会拦截 `a[download]`，此时会提示长按保存。
- **二维码是固定版本**：`src/qr.js` 固定 Version 4 / 纠错 L，容量 78 字节，足够当前线上地址；若以后域名更长，需要升级版本或换短链。
- 长句（13 词以上）的组句在手机上略长，已通过"只保留 2 句以内"的内容规范控制。

## 隐私与合规

- 无账号、无埋点、无网络请求；进度只存在本机，可在「人设 → 清除本机所有进度」一键删除。
- 无陌生人社交、无 UGC 公开展示、无地理位置。
- 内容不含恋爱引导、外貌评价、攀比消费；冲突剧情以"修复关系"为落点。
- 不宣称提分，主打"敢开口"。
